# public/

Add two files here before deploying:

- **`resume.pdf`** — every "Resume" button links to `/resume.pdf`. Deliberately
  not included in the repo; add your real résumé.
- **`portrait.jpg`** — optional headshot for the About section. Its presence is
  checked at build time, so without it the section renders a monogram plate
  with no failed request. Roughly 4:5 portrait crop works best.
